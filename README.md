# ECOVACS India — Flagship Robotics Landing Page

Official web landing page experience for **ECOVACS India**, featuring next-generation autonomous cleaning robots across the DEEBOT T-Series, X-Series, N-Series, WINBOT window cleaners, and GOAT robotic lawn mowers.

---

## 🌟 Key Features

- **Responsive Launch Banner**: Dynamic HTML5 `<picture>` delivery serving high-resolution portrait banner (`Ecovacs_M.jpg`) on mobile viewports ($\le 640\text{px}$) and panoramic banner (`Ecovacs_Banner.jpg`) on desktop without cropping.
- **Glassmorphic Navigation**: Optical frosted glass navbar with `$16\text{px}$` backdrop blur, saturation boost, specular light reflection, and smooth hover pill states.
- **Why Ecovacs Bento Grid**: 5×2 dynamic morphing feature grid with smooth FLIP expansion animations for deep dive technical specs.
- **Find Your Ideal Cleaner**: Interactive seasonal and floor-concern matcher providing model recommendations, real-time match gauge, and capability breakdown bars.
- **Experience Stores Hub**: 1-click booking for India flagship studios across 24+ cities pan-India.
- **Curated Product Lineup**: Comprehensive comparison with specs, EMI calculations, and direct purchase links.
- **Smooth Inertial Scrolling**: Integrated with lightweight [Lenis](https://lenis.darkroom.engineering/) for 60fps smooth scrolling with sticky header offset anchor navigation.
- **Mobile-First Responsiveness**: Tailored layouts across iPhone, Android, tablet, and desktop viewports with zero horizontal overflow.

## 🚀 Quick Start

To preview locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/zubia-quadri/ecovacs-india.git
   cd ecovacs-india
   ```
2. Open `index.html` directly in any modern browser:
   - On Windows: double-click `index.html` or run `start index.html`
   - Or serve with any static web server (e.g. `npx serve`, Live Server in VS Code, etc.).
